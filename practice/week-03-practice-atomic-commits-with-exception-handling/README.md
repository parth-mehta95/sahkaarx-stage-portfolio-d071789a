# Practice Atomic Commits with Exception Handling

## Task Brief
Create focused, atomic commits demonstrating clean version control while implementing exception handling features.

## Scenario
Your team reviews commit quality; demonstrate professional practices by creating 3-5 atomic commits on an exception-handling feature branch.

## Deliverables
- Feature branch with 3-5 atomic commits
- Pull request with clear commit messages
- Merged changes on main branch

## Success Criteria
- Each commit addresses one logical change
- Commit messages follow best practices
- All commits merged to main with clean history

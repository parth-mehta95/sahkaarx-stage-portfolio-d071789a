# Practice Atomic Commits and Branching Workflow

## Task Brief
Create feature branches with atomic commits following best practices, then merge via pull request to demonstrate clean version control.

## Scenario
Your team reviews code quality; you demonstrate professional commit practices by creating focused, atomic commits on a feature branch.

## Deliverables
- Feature branch with 3-5 atomic commits
- Pull request with clear commit messages
- Merged changes on main branch

## Success Criteria
- Each commit addresses one logical change
- Commit messages follow conventions
- PR shows clean, reviewable history

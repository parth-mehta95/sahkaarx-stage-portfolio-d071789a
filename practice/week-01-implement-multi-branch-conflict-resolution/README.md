# Implement Multi-Branch Conflict Resolution

## Task Brief
Create overlapping feature branches, trigger real merge conflicts, resolve them manually, and document the resolution process.

## Scenario
Your team develops multiple overlapping features; you manage two branches, resolve conflicts between them, and document the process.

## Deliverables
- Two feature branches with documented conflicts
- Conflict resolution documentation
- All branches merged to main

## Success Criteria
- Both feature branches created and pushed
- Conflicts identified and resolved manually
- Documentation explains resolution strategy

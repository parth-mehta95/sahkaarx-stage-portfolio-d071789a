# Create Feature Branch and Resolve Merge Conflict

## Task Brief
Extend your GitHub portfolio by creating a feature branch, simulating a merge conflict, resolving it manually, and merging via pull request.

## Scenario
Your team is adding a new feature. Create a branch, trigger a conflict, resolve it, and merge with a clear PR.

## Deliverables
- Feature branch with conflict resolution
- Merged pull request with commit history

## Success Criteria
- Conflict manually resolved and committed
- PR merged with descriptive messages

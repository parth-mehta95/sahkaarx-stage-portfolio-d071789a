# Implement Multi-Branch Conflict Resolution

## Task Brief
Create overlapping feature branches, trigger real merge conflicts, resolve them manually, and document the resolution process in your portfolio.

## Scenario
Your team is developing competing features. Resolve conflicts across branches and merge cleanly via pull request.

## Deliverables
- Two feature branches with documented conflict resolution
- Merged pull request with clear commit history

## Success Criteria
- Conflicts resolved manually without merge tools
- Pull request approved and merged to main

# Create Feature Branch and Resolve Merge Conflict

## Task Brief
Extend your GitHub portfolio by creating a feature branch, simulating a merge conflict, resolving it manually, and merging via pull request.

## Scenario
Your team is adding a new feature; you create a branch, encounter a merge conflict with main, resolve it, and merge cleanly.

## Deliverables
- Feature branch with conflict resolution
- Pull request showing conflict resolution
- Updated main branch with merged changes

## Success Criteria
- Conflict markers resolved manually and correctly
- PR shows clear commit history
- Feature successfully merged to main

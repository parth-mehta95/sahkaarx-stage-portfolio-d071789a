# Implement Conflict Resolution in Portfolio Project

## Task Brief
Extend your GitHub portfolio by creating overlapping feature branches, simulating merge conflicts, resolving them, and merging via pull request.

## Scenario
Your team adds overlapping features to the portfolio app; you manage branches, resolve conflicts between them, and merge cleanly.

## Deliverables
- Pull request showing conflict resolution
- Merged branches with clean history
- Conflict resolution comments in PR

## Success Criteria
- PR demonstrates manual conflict resolution
- All conflicts resolved without data loss
- Commit history is clean and atomic
